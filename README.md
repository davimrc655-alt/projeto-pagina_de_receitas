# projeto-pagina_de_receitas
# 🥕 Projeto Receita Completa - Bolo de Cenoura

Uma página web responsiva e semântica desenvolvida para apresentar uma receita tradicional de bolo de cenoura com cobertura. O projeto foi construído do absoluto zero, sem o uso de frameworks, focando na aplicação prática de estruturas de texto e estilização avançada com CSS3.

O objetivo principal deste repositório foi vencer o bloqueio de desenvolvimento ("página em branco") através do planejamento prévio em papel e execução autônoma de código.

---

## 🎨 Design & Estética Visual (Vibe "Chef de Cozinha")
- **Paleta de Cores:** Escolha de tons baseados na culinária, utilizando o verde oliva (`#606C38`) como container principal, contrastando com o vermelho terracota (`#D62828`) nos títulos para abrir o apetite do usuário.
- **Tipografia:** Importação e uso de fontes personalizadas do Google Fonts (`Cedarville Cursive`) para dar um toque manuscrito e elegante de "caderno de receitas" no título e na assinatura.
- **Layout Confortável:** Foco na legibilidade do texto no mobile com ajustes finos de `line-height` e espaçamentos internos para que o usuário possa ler enquanto cozinha.

---

## 🛠️ Tecnologias e Conceitos Aplicados
- **HTML5 Semântico Avançado:** Uso correto de estruturas de listas não ordenadas (`<ul>`) para ingredientes, listas ordenadas (`<ol>`) para o passo a passo sequencial, e a tag `<blockquote>` para isolar e destacar dicas importantes.
- **CSS3 Moderno:** * Controle de fluxo com **Flexbox** no `header`, `main` e `body`.
  * Efeitos de profundidade e contraste através de `text-shadow`.
  * Manipulação do Box Model com `max-width` e `width: 100%` para garantir responsividade nativa (se adapta a qualquer tela de celular).
  * Alinhamento inteligente do rodapé na base da tela usando `margin-top: auto` no Flexbox.

---

## 🧠 Desafios Superados e Aprendizados
1. **Independência no Código:** Todo o HTML e a estilização CSS foram planejados e escritos de forma 100% autônoma, consolidando a lógica de herança e seletores do CSS.
2. **Casamento de Tags e Flexbox:** Correção do comportamento do `body` como container flex para permitir que o rodapé flutuasse corretamente até a base, prevenindo espaços em branco indesejados.
3. **Responsividade de Imagens:** Aplicação de propriedades de proporção na imagem do bolo para que ela se ajuste sem distorcer em telas menores.
